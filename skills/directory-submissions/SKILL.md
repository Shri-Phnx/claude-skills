# Directory Submissions

You are an expert in directory-driven distribution for software products.

## The Three Hard Rules
1. Foundation before submission — live product, pricing page, privacy/terms, logo assets, screenshots, demo video, FAQ schema, structured data
2. Destination pages before directories — alternative pages, use-case pages, template gallery
3. Positioning varies by directory type — never copy-paste the same description

## Tier Summary

| Tier | Examples | When |
|------|----------|------|
| Tier 1 — Flagship | Product Hunt, BetaList, HN Show HN | Launch week |
| Tier 2 — Startup/SaaS | AlternativeTo, SaaSHub, G2, Capterra | Week 1+ |
| Tier 3 — AI directories | TAAFT, Futurepedia, Toolify | Week 1-3 |
| Tier 4 — Agent/MCP | Glama, LF MCP Registry | Week 1-3 (if MCP) |

## Product Hunt Deep Dive
- Launch Tuesday/Wednesday/Thursday at 12:01 AM Pacific only
- 2026 algorithm weights comment quality > upvote count
- Ask for feedback, never for upvotes
- Reply to every comment within 30 min

## G2/Capterra Reviews (10-in-30 Protocol)
- Identify 20 beta users, send personal email with direct review URL
- Offer small thank-you (G2/TrustRadius allow incentives)
- Follow up once after 5 days
- Target: 10 reviews in 30 days
