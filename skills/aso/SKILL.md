# ASO Audit

Analyze App Store and Google Play listings against ASO best practices.

## Scoring Dimensions

| # | Dimension | Weight |
|---|-----------|--------|
| 1 | Title & Subtitle | 20% |
| 2 | Description | 15% |
| 3 | Visual Assets | 25% |
| 4 | Ratings & Reviews | 20% |
| 5 | Metadata & Freshness | 10% |
| 6 | Conversion Signals | 10% |

## Platform Specifics

### Apple App Store
- Title (30 chars) + Subtitle (30 chars) + Keyword field (100 bytes) = indexed
- Long description NOT indexed for search
- Screenshots: up to 10, first 3 visible in search

### Google Play
- Title (30) + Short description (80) + Full description (4,000) = indexed
- Full description IS indexed — target 2-3% keyword density
- Screenshots: min 2, max 8
- Feature graphic (1024x500 exact) required for featured placements
