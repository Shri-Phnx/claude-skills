# Claude Skills

Skills for Claude (Cowork / Claude Desktop). Each file is named after the skill — e.g. `skeptical-vc-red-team.md`, not `SKILL.md`.

These are personal reference copies. The live versions installed in Cowork live under `skills/[skill-name]/SKILL.md`.

## Naming Convention

- File name: `[skill-name].md` (e.g. `skeptical-vc-red-team.md`)
- No SKILL.md naming here
- Mirrors local folder: `C:\Users\PC\Documents\Claude\Skills\Claude Skills\`
